# WebSee

폴더, 이미지, TXT/TEXT 텍스트 파일, ZIP/CBZ/RAR/CBR 압축파일을 Chrome 안에서 바로 탐색하는 읽기 전용 뷰어 확장 프로그램입니다. 선택한 파일은 외부로 전송하지 않습니다.

## 지원 기능

- 로컬 폴더에서 이미지, TXT/TEXT와 ZIP/CBZ/RAR/CBR을 한 목록으로 열기
- TXT/TEXT 왼쪽 미리보기 및 전용 상세보기(UTF-8, UTF-16, CP949 자동 판별)
- 왼쪽 탐색 트리에서 폴더, 압축파일, 압축 내부 폴더 열기
- Chrome에서 폴더 드래그앤드롭 및 목록 새로고침
- ZIP/CBZ/RAR/CBR 내부 폴더 및 이미지 탐색
- 압축파일을 열면 썸네일과 해상도를 순차적으로 만드는 백그라운드 인덱싱
- 처리한 원본은 즉시 버리고 경량 썸네일만 유지하며, 선택한 이미지만 원본 상세보기로 캐시
- 썸네일과 상세 목록 보기
- 자연스러운 숫자 파일명 정렬
- 확대, 이동, 화면 맞춤, 폭 맞춤, 100%, 회전, GPU 기반 화질 개선
- 옵션에서 활성화할 수 있는 일본어·중국어·영어 이미지 오버레이 번역
- 번역 기능 활성화 시 현재 폴더 이미지와 ZIP·CBZ·RAR·CBR 내부 이미지를 순차 처리하는 일괄 번역
- 전체화면과 옵션에서 활성화할 수 있는 3·5·10초 간격 슬라이드쇼 및 반복 재생
- 파일명, 크기, 형식, 해상도 표시

지원 이미지 형식은 JPEG, PNG, GIF, WebP, AVIF, BMP, SVG, ICO이며, 텍스트는 TXT와 TEXT를 지원합니다. 실제 이미지 표시는 실행 중인 브라우저의 decoder 지원 범위를 따릅니다. 암호화된 압축파일, 분할 RAR, 중첩 압축파일과 압축파일 내부 텍스트는 지원하지 않습니다.

이미지 번역은 현재 열어 본 한 장에만 실행됩니다. 최초 사용 시 텍스트 영역 감지 모델 약 11MB를 받고, 텍스트가 발견되면 Baberu OCR 모델 약 121MB를 추가로 내려받아 브라우저에 캐시합니다. 이후 OCR은 로컬에서 처리하며 원본 이미지를 외부로 보내지 않습니다. 한국어 번역에는 최신 Chrome의 내장 `Translator API`를 사용하고, Chrome이 관리하는 언어 모델이 별도로 준비될 수 있습니다. 저장된 OCR 모델은 메인 툴바의 `옵션`에서 제거할 수 있습니다.

`폴더 열기`로 연 파일은 쓰기 권한을 허용하면 원본 폴더의 `.websee` 하위에 번역 결과를 JSON으로 저장합니다. 일반 이미지는 `.websee/<이미지 파일명>.json`, 압축파일은 `.websee/<압축파일명>.json` 하나에 내부 이미지 경로별로 기록하며, 원본 크기와 수정 시각이 일치할 때 다음 실행에서 우선 불러옵니다. 메인 툴바의 `옵션`에서 현재 폴더의 저장 용량을 확인하고, 원본이 사라진 번역 데이터만 정리하거나 현재 폴더 데이터를 모두 삭제할 수 있습니다. 폴더 업로드 입력이나 개별 파일 열기로 연 항목은 폴더 쓰기 핸들이 없어 이번 실행 중에만 결과가 유지됩니다.

툴바의 `일괄 번역`은 현재 폴더의 일반 이미지와 선택적으로 압축파일 내부 이미지까지 한 장씩 처리하고, 완료된 결과를 즉시 저장합니다. 저장된 결과 건너뛰기가 기본값이므로 중지하거나 Chrome을 닫은 뒤 같은 폴더에서 다시 실행하면 남은 항목부터 이어집니다. 하위 폴더는 일괄 번역 대상에 포함하지 않습니다.

## Chrome에 설치

```sh
npm install
npm run build
```

1. Chrome에서 `chrome://extensions`를 엽니다.
2. 오른쪽 위의 `개발자 모드`를 켭니다.
3. `압축해제된 확장 프로그램을 로드합니다`를 누릅니다.
4. 이 프로젝트의 `dist` 폴더를 선택합니다.
5. WebSee를 툴바에 고정한 뒤 아이콘을 누르면 전체 탭으로 열립니다.

코드를 수정한 뒤에는 `npm run build`를 다시 실행하고 확장 프로그램 카드의 `새로고침` 버튼을 누릅니다.

## 개발 서버

확장 프로그램으로 설치하지 않고 UI를 빠르게 개발할 때는 기존 Vite 서버도 사용할 수 있습니다.

```sh
npm run dev
```

확장 프로그램과 개발 서버 모두 로컬 폴더 접근 권한은 사용자가 폴더를 선택하거나 드롭한 범위에서만 부여됩니다.
